# AE2 Mod ID View Cell

AE2 Mod ID View Cell adds an Applied Energistics 2 View Cell variant that filters terminal contents by mod ID.

This branch is a rewrite for Minecraft 1.21.1, NeoForge, and modern AE2. It keeps the original idea of the 1.12.2 mod, but rebuilds it around current AE2 view-cell filtering, GuideME docs, data components, and the new GUI.

## Links

- [Features and usage](FEATURES.md)
- [Changelog](CHANGELOG.md)

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.x
- Applied Energistics 2 19.x

## Building

Import the project into your IDE or build it with Gradle:

```powershell
.\gradlew.bat build
```
